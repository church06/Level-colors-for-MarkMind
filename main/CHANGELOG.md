# Changelog

All notable changes to this project will be documented here.

## 1.0.0 - 2026-09-08

Initial public release.

- Automatic hierarchy-level colouring for MarkMind Basic.
- Node, branch-curve, and underline colouring.
- Logical tree traversal for underline assignment.
- Automatic refresh after relevant layout/render changes.
- Desktop and mobile-compatible plugin manifest.
